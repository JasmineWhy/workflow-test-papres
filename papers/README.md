## PDF 不入 git 仓库

本目录 PDF 原件被 `.gitignore` 排除（arXiv 论文再分发授权因文而异 + 体积考虑，与 [3D24D_paper](https://github.com/JasmineWhy/3D24D_paper) 仓库同一策略）。克隆本仓库后一条命令自取：

```bash
bash resume_pdfs.sh 8 480      # 并发 8 路、单轮预算 480 秒，可反复执行（断点续传）
```

已完成下载的文件自动跳过（SKIP），中断后重跑即可续传；脚本自带完整性校验（`%PDF` 头 + `EOF` 尾标记双判据）。

## 下载方案（沿袭 3D24D_paper 实测经验）

- arXiv 国际线路单连接实测仅 18–47 KB/s，**并发 + 断点续传**是唯一可行解：并发 8 路 × 续传轮次。
- 本批 65 篇共 132 MB，8 路并发约 10 分钟完成（两轮内）。
- 踩坑记录：`xargs -P N` 会按列表顺序取任务，大文件霸占槽位时靠续传跨轮完成；ZCode + Git Bash 后台任务不可靠，**前台分轮跑**。
- 本仓库脚本相对原版修复：ID 清单过滤改为 `grep -E '^[0-9]{4}\.[0-9]{4,5}'`（原 `grep -v '^#'` 会把空行当任务，导致空转轮）。
